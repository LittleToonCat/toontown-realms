**Toontown Realms**
================

Toontown Realms is a sandbox interpretation of Toontown Online.

This Open Source release is based on an in-development version of what was supposed to be Beta 2. 
Incomplete, unreleased features are in this codebase, such as Sellbot Showdown, Prop Hunt, Dreamy Drive, and a new cog system. Most of these are very incomplete.

The code quality of this project is also generally poor.

While it's open source, this is not an _actively_ developed project by the Realms Team.
Pull Requests that improve, update, finish, or fix any aspect of the game are welcome.



**Panda3D**
================

Toontown Realms uses a unique version of Panda3D. Please go download it at the link for your operating system below in order to run the game.

Windows: [Panda3D SDK for Windows (x86_64)](https://hostiletakeover.co/dl/realms/Panda3D-TTRMDev-1.11.0-py3.14-x64.exe) (COMING SOON)

Linux: Install [this python wheel](https://hostiletakeover.co/dl/realms/panda3d-1.11.0-cp314-cp314-linux_x86_64.whl) onto a Python 3.14 installation.

Engine Source: [our own Panda3D repository.](https://github.com/ttoff/panda3d/tree/beta2-engine) - (beta2-engine branch required)
